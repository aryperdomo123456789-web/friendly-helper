# Documentação Especialista do MAGOPLAYERPRO

Este diretório reúne a documentação técnica, operacional, de arquitetura,
auditoria, migração e execução do projeto.

Comece por [`00-GUIA-ESPECIALISTA-MAGOPLAYERPRO.md`](00-GUIA-ESPECIALISTA-MAGOPLAYERPRO.md).

## Organização

- Arquivos na raiz: visão geral, execução por fases, auditoria e operação.
- `deploy/`: arquitetura de produção, PM2, banco, migrations, chat, pagamentos,
  catálogo, cache e checklists especializados.

Os scripts, configurações e migrations continuam nos diretórios técnicos do
projeto (`deploy/`, `supabase/` e `src/`). Apenas a documentação foi reunida
aqui.
